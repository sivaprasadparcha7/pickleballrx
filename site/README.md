# PickleballRx.org

Plain HTML site. Upload the contents of this folder to public_html.

## Adding your images (no code needed)
Drop image files into these folders with these exact names, then send the folder back to Claude to rebuild (or just upload; X-ray/grit images are picked up on the next build).

- X-rays: assets/xray/<paddle>-clean.jpg, <paddle>-labeled.jpg, <paddle>-density.jpg
  e.g. assets/xray/rpm-jade-labeled.jpg  (paddle names = the file names in the xray/ folder)
- Microscope (M lens): assets/grit/<paddle>.jpg  e.g. assets/grit/rpm-jade.jpg

Data lives in ../data/ and pages are generated by ../build.py. See the README at the top of the repository.
